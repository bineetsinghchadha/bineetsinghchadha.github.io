# Personal site

Source for my portfolio and project blog, served with GitHub Pages.

- `index.html` is the portfolio page.
- `blog/` holds one write-up per project and the shared stylesheet `blog.css`.
- Files in `blog/` whose names start with `_` are drafts. GitHub Pages does not serve them.

The site is plain HTML and CSS with no build step. To preview it, open `index.html` in a browser.
